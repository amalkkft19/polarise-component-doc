# Components

This directory contains detailed documentation for every Shopify Polaris web component.

## Index

### Actions
- [Button](./components/button.md) — Trigger actions or navigate to a new location.

### Forms
- [TextField](./components/text-field.md) — Enter and edit text.
- [Select](./components/select.md) — Choose one option from a list.
- [Checkbox](./components/checkbox.md) — Toggle a setting on or off.
- [RadioButton](./components/radio-button.md) — Choose one option from a related set.

### Feedback Indicators
- [Badge](./components/badge.md) — Communicate the status of an object.
- [Banner](./components/banner.md) — Display important changes or persistent conditions.
- [Spinner](./components/spinner.md) — Show a loading state.

### Structure
- [Card](./components/card.md) — Group related content and actions.
- [Page](./components/page.md) — Build the outer wrapper of a page.
- [Layout](./components/layout.md) — Arrange content in a responsive grid.

### Overlays
- [Modal](./components/modal.md) — Interrupt with urgent information or actions.
- [Popover](./components/popover.md) — Display contextual actions or information.
- [Tooltip](./components/tooltip.md) — Display additional information on hover or focus.

### Images & Icons
- [Icon](./components/icon.md) — Render an SVG icon from the Polaris icon set.
