Polaris Web Components

Framework-agnostic custom elements that implement the Shopify Polaris design language. Build high-quality merchant interfaces faster.

⚡

Framework-agnostic

Works with React, Vue, Angular, Svelte, or plain HTML. No framework lock-in.

♿

Accessible by default

🎨

Themeable

CSS custom properties expose all design tokens for easy customisation.

📦

Tree-shakeable

ES modules mean you only ship the components you actually use.

Installation

Add Polaris web components to your project in minutes.

npm

Install the package from the npm registry:

Terminal
npm install @shopify/polaris

Then import the package in your JavaScript entry point:

JavaScript
import '@shopify/polaris';
import '@shopify/polaris/build/esm/styles.css';

CDN

For prototyping or non-bundled projects, include the CDN bundle directly:

HTML
<link rel="stylesheet"
      href="https://unpkg.com/@shopify/polaris/build/esm/styles.css" />
<script type="module"
        src="https://unpkg.com/@shopify/polaris/build/esm/index.js"></script>

Basic usage

Once installed, use the components directly in HTML:

HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>My Shopify App</title>
  <link rel="stylesheet"
        href="https://unpkg.com/@shopify/polaris/build/esm/styles.css" />
</head>
<body>
  <p-button variant="primary">Save changes</p-button>

  <script type="module">
    import 'https://unpkg.com/@shopify/polaris/build/esm/index.js';
  </script>
</body>
</html>

With React

React (JSX)
import '@shopify/polaris';
import '@shopify/polaris/build/esm/styles.css';

export default function MyComponent() {
  return (
    <p-button variant="primary"
              onP-click={() => console.log('Clicked!')}>
      Save changes
    </p-button>
  );
}

Browser support

Polaris web components support all modern browsers that implement the Custom Elements v1 specification:

  • Chrome 67+
  • Firefox 63+
  • Safari 12.1+
  • Edge 79+
Home › Actions

Button

Buttons trigger actions or navigate to a new location. Use them for the most important actions on a page.

Examples

Default
<p-button>Add product</p-button>
Primary
<p-button variant="primary">Save changes</p-button>
Destructive
<p-button variant="destructive">Delete product</p-button>
Plain
<p-button variant="plain">View details</p-button>
Sizes
<p-button size="slim">Slim</p-button>
<p-button>Medium</p-button>
<p-button size="large">Large</p-button>
Disabled
<p-button disabled>Save changes</p-button>
<p-button variant="primary" disabled>Save changes</p-button>

Props

PropTypeDefaultDescription
variantstring"default"Visual style: "primary", "destructive", "plain", "monochrome".
sizestring"medium"Size: "slim", "medium", "large".
disabledbooleanfalsePrevents interaction.
loadingbooleanfalseShows a loading spinner; disables the button.
full-widthbooleanfalseMakes the button fill its container.
urlstring—Renders the button as an anchor element.
externalbooleanfalseOpens url in a new tab.
disclosurebooleanfalseShows a chevron indicating an overlay opens.
iconstring—Icon name to show before the button text.

Events

EventDescription
clickFired when the button is activated (unless disabled or loading).

Banner

Banners communicate important changes or persistent conditions. They should be used sparingly.

Examples

Informational
ℹ️
Before you add a product
Your store doesn't have the Shipping app installed. Install it before adding products. 
<p-banner title="Before you add a product" status="info">
  Your store doesn't have the Shipping app installed.
</p-banner>
Success
✅
Shipment label created
Your shipping label for Order #1001 is ready to download. 
<p-banner title="Shipment label created" status="success" dismissible>
  Your shipping label for Order #1001 is ready to download.
</p-banner>
Warning
⚠️
Some products are unavailable
5 products have 0 inventory. Update inventory to make them available. 
<p-banner title="Some products are unavailable" status="warning">
  5 products have 0 inventory.
</p-banner>
Critical
🚨
Your payment was declined
Add a new payment method to continue using Shopify. 
<p-banner title="Your payment was declined" status="critical">
  Add a new payment method to continue using Shopify.
</p-banner>

Props

PropTypeDefaultDescription
titlestring—Banner heading.
statusstring—"success", "info", "warning", "critical".
action-contentstring—Label for the primary action button.
action-urlstring—URL for the primary action.
secondary-action-contentstring—Label for the secondary action.
dismissiblebooleanfalseShows a dismiss button.

Events

EventDescription
p-actionFires when the primary action is clicked.
p-dismissFires when the dismiss button is clicked.

TextField

Text fields let merchants enter and edit text. They support a variety of types and validation states.

Examples

Basic
<p-text-field
  label="Product title"
  placeholder="Short sleeve T-shirt"
></p-text-field>
With help text
We'll use this address to send order confirmations. 
<p-text-field
  label="Email"
  type="email"
  help-text="We'll use this address to send order confirmations."
></p-text-field>
With error
Price must be greater than zero. 
<p-text-field
  label="Price"
  type="number"
  value="-5"
  error="Price must be greater than zero."
></p-text-field>

Props

PropTypeDefaultDescription
labelstring—Visible label. Required.
valuestring""Current field value.
typestring"text"HTML input type.
placeholderstring—Placeholder text.
help-textstring—Descriptive text below the field.
errorstring—Error message; puts field in error state.
disabledbooleanfalsePrevents interaction.
read-onlybooleanfalseValue readable but not editable.
multilinebooleanfalseRenders a <textarea>.
max-lengthnumber—Maximum character count.
prefixstring—Text shown before the input value.
suffixstring—Text shown after the input value.

Events

EventDescription
p-changeFires when the value changes.
p-focusFires when the field receives focus.
p-blurFires when the field loses focus.

Page

The page component builds the outer wrapper of a page, including the title, back navigation, and action buttons.

Examples

Page with primary action
<p-page
  title="Products"
  back-action-content="Home"
  back-action-url="/"
>
  <p-button slot="primary-action" variant="primary" url="/products/new">
    Add product
  </p-button>

  <p-card sectioned>
    <p>Your product list will appear here.</p>
  </p-card>
</p-page>

Props

PropTypeDefaultDescription
titlestring—Page heading. Required.
subtitlestring—Subtitle below the heading.
back-action-contentstring—Back link label.
back-action-urlstring—Back link URL.
full-widthbooleanfalseExtends page to full container width.
narrow-widthbooleanfalseConstrains page to a narrower width.

Slots

SlotDescription
(default)Page content.
primary-actionPrimary action button.
secondary-actionsSecondary action buttons.

Layout

The layout component creates the main structure of a page using a responsive grid.

Examples

Two-column layout
<p-layout>
  <p-layout-section one-half>
    <p-card title="Revenue" sectioned>
      £12,300 this month
    </p-card>
  </p-layout-section>
  <p-layout-section one-half>
    <p-card title="Orders" sectioned>
      342 orders this month
    </p-card>
  </p-layout-section>
</p-layout>
Annotated layout
<p-layout>
  <p-layout-annotated-section
    title="Store details"
    description="Shopify and your customers will use this to contact you."
  >
    <p-card sectioned>
      <p-text-field label="Store name"></p-text-field>
    </p-card>
  </p-layout-annotated-section>
</p-layout>

LayoutSection props

PropTypeDefaultDescription
one-halfbooleanfalseSection takes half the row width.
one-thirdbooleanfalseSection takes a third of the row width.
secondarybooleanfalseActs as a sidebar (one-third, right side).

Modal

Modals interrupt merchants with urgent information, details, or actions. Use them sparingly.

Examples

Basic modal
<p-modal
  title="Import products"
  primary-action-content="Import"
  secondary-action-content="Cancel"
>
  Your CSV file has been uploaded and will be imported as products.
  This can take up to 5 minutes.
</p-modal>
Destructive modal
<p-modal
  title="Delete product?"
  primary-action-content="Delete"
  secondary-action-content="Cancel"
  destructive
>
  Are you sure? This action cannot be reversed.
</p-modal>

Props

PropTypeDefaultDescription
openbooleanfalseWhether the modal is visible.
titlestring—Modal heading. Required.
primary-action-contentstring—Primary button label.
secondary-action-contentstring—Secondary button label.
destructivebooleanfalseStyles primary action as destructive.
largebooleanfalseIncreases modal width.

Events

EventDescription
p-closeFires when the modal is dismissed.
p-primary-actionFires when the primary action is clicked.
p-secondary-actionFires when the secondary action is clicked.

Popover

Popovers are small overlays that open on demand, used for contextual actions or information.

Examples

With action list
<p-popover>
  <p-button slot="activator" disclosure>More actions</p-button>

  <p-action-list>
    <p-action-list-item>Duplicate</p-action-list-item>
    <p-action-list-item>Archive</p-action-list-item>
    <p-action-list-item destructive>Delete</p-action-list-item>
  </p-action-list>
</p-popover>

Props

PropTypeDefaultDescription
activebooleanfalseWhether the popover is visible.
preferred-alignmentstring"left"Horizontal alignment: "left", "right", "center".
preferred-positionstring"below"Vertical position: "above", "below", "mostSpace".
full-widthbooleanfalseMatches the activator width.
